One single-line office joke, written to win a head-to-head judge: the office plants all died, so management replaced them with a poster of a forest and called it the wellness program. A Node 22 program (`main.ts`) writes the joke (117 characters) to `entry.txt` in the output directory. Setup, turn, payoff — all in one line, no word wasted.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
